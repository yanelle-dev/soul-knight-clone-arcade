# Soul Knight Clone (Arcade)

2D-аркадный roguelike на Python с процедурной генерацией подземелий, волнами врагов и системой прогрессии.

## О проекте

Клон Soul Knight: игрок исследует процедурно генерируемые подземелья, сражается с волнами врагов, собирает кристаллы, открывает скины и оружие. Лобби служит хабом для кастомизации перед каждым забегом.

## Возможности

- **Процедурная генерация** — комнаты и коридоры создаются заново на каждом уровне.
- **Система волн** — каждая комната зачищается волнами врагов; двери открываются после победы.
- **4 типа врагов** — Zombie, Robot (стреляет), Slime (танк), Bat (быстрый).
- **Босс** — появляется на 3-м уровне, стреляет веером из 5 пуль.
- **2 оружия** — Sword (ближний бой, 15 урона) и Blaster (дальний бой, 5 урона, скорострельный).
- **Скины персонажа** — 4 скина с покупкой за кристаллы.
- **Предметы** — кристаллы (валюта), зелья лечения, щиты, сундуки.
- **Частицы** — эффекты попаданий.
- **SQLite** — сохранение кристаллов, разблокированных скинов и оружия.

## Состояния игры

| Состояние | Описание |
|-----------|----------|
| `MENU` | Главное меню — Enter для входа в лобби |
| `LOBBY` | Хаб: портал (E), шкафчик скинов (E), оружейная (E) |
| `PLAYING` | Исследование подземелья, бои |
| `PAUSED` | Пауза — P для продолжения |
| `GAME_OVER` | Смерть — R для рестарта |
| `VICTORY` | Победа над боссом на 3-м уровне |
| `SKIN_SELECT` | Меню выбора скина |
| `WEAPON_SELECT` | Меню оружейной |

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Движение |
| Мышь | Направление взгляда / стрельбы |
| ЛКМ | Стрельба / удар мечом |
| E | Взаимодействие (портал, шкафчик, оружейная) |
| Enter | Подтверждение в меню |
| P | Пауза / продолжение |
| Escape | Выход |

## Подземелье

### Генерация

1. **Комнаты** — 2 случайных комнаты (6–12 тайлов), без пересечений.
2. **Коридоры** — L-образные туннели между комнатами.
3. **Двери** — по периметру каждой комнаты; скрыты до зачистки.
4. **Стены** — генерируются вокруг всех тайлов пола.
5. **Сундуки** — 70% шанс в каждой обычной комнате.

### Комнаты

| Индекс | Назначение | Волны |
|--------|-----------|-------|
| 0 (стартовая) | Без врагов | 0 |
| 1..N-2 (обычные) | Боевые | 2–3 волны |
| Последняя (уровень 3) | Босс | 1 волна |

### Враги

| Враг | HP | Скорость | Урон | Поведение |
|------|----|----------|------|-----------|
| Zombie | 30 | 2.0 | 10 | Ближний бой, преследование |
| Robot | 40 | 1.0 | 15 | Стреляет с кулдауном 2с, дальность 300 |
| Slime | 80 | 0.8 | 20 | Танк, ближний бой |
| Bat | 15 | 4.0 | 5 | Быстрый, ближний бой |
| Boss | 500 | 1.5 | 25 | Стреляет веером из 5 пуль каждые 0.8с |

## Предметы

| Предмет | Описание |
|---------|----------|
| CrystalDrop | Кристаллы (5 шт.), анимация пульсации |
| HealthPotion | Лечение +20 HP |
| ShieldItem | Щит +25 брони (макс. 50) |
| Chest | Сундук: 40% Blaster, 30% зелье, 30% щит |
| WeaponDrop | Выпавшее оружие из сундука |

## Оружие

| Оружие | Тип | Урон | Кулдаун | Особенность |
|--------|-----|------|---------|-------------|
| Sword | Ближний бой | 15 | 0.4с | Радиус 70px |
| Blaster | Дальний бой | 5 | 0.1с | Скорострельный, пули со скоростью 15 |

## Лобби

Лобби — статичная арена 1024×768 с тремя интерактивными объектами:

| Объект | Позиция | Действие |
|--------|---------|----------|
| Портал | Верх центра | Начать забег |
| Шкафчик скинов | Слева | Открыть меню скинов |
| Оружейная | Справа | Открыть меню оружия |

## База данных (SQLite)

Таблицы:

| Таблица | Поля | Назначение |
|---------|------|------------|
| `player` | id, crystals | Баланс кристаллов |
| `unlocked_skins` | skin_name | Разблокированные скины |
| `unlocked_weapons` | weapon_name | Разблокированное оружие |

При инициализации создаются: 1 кристалл, скин "Adventurer", оружие "Sword".

## Конфигурация (config.py)

Ключевые параметры:

| Параметр | Значение | Описание |
|----------|----------|----------|
| `SCREEN_WIDTH/HEIGHT` | 1024×768 | Размер окна |
| `PLAYER_SPEED` | 3.5 | Скорость движения |
| `PLAYER_MAX_HP` | 100 | Макс. здоровье |
| `PLAYER_MAX_ARMOR` | 50 | Макс. щит |
| `BULLET_SPEED` | 12 | Скорость пули |
| `SPRITE_SCALING` | 0.5 | Масштаб спрайтов |

Скины: Adventurer (0), Knight (50), Robot (100), Zombie (200).

## Запуск

Требования: Python 3.10+, библиотека `arcade`.

```bash
cd soul-knight-clone-arcade

# Зависимости
pip install -r requirements.txt

# Запуск
python main.py
```

## Сборка (PyInstaller)

```bash
pip install pyinstaller
pyinstaller main.spec
```

Бинарник появится в `dist/`.
